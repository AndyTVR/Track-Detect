Activity in ROI

Y-axis

Drag the blue line to set the detection level: spikes above it become events, spikes below it (grey) are ignored. Scroll to zoom, drag to pan, click to jump to that moment. Use the time window to pick a stretch of the recording. The y-axis options stop one tall spike flattening the rest: Auto cuts off spikes that dwarf the others (marked ▲), Log squeezes tall spikes down. They only change the view, not which events are found.
