Y-axis

Drag the blue line to set the detection level: spikes above it become events, spikes below it (grey) are ignored. Scroll to zoom, drag to pan, click to jump to that moment. Use the time window to pick a stretch of the recording. Default sets the height from the suggested detection level, so the line sits a quarter of the way up and the noise and small spikes are easy to see. Linear automatically cuts off spikes that dwarf the others (marked ▲); drag the handle on the bar left of the plot to set the height yourself. Log squeezes tall spikes down. These only change the view, not which events are found.

Custom filters Advanced

This is an advanced option. Please read the Track & Detect manual first: it explains what each filter does and when it helps. The Default, Tracking and Detection modes are the recommended way to review footage.

Build your own filter for the Custom viewing mode: start from scratch: tick the filters you want, set their frames, and choose whether to blend it with the thermal picture. Saved filters appear in the Custom mode's dropdown. They change only what you see, never the scan.

Filters, applied in this order frames · keeps the brightest value of recent frames, leaving trails frames · shows only what changed, so moving animals stand out

Some filters can conflict and give unexpected results, such as a blank or washed-out picture. Check how a new filter looks before relying on it.

    Time & units

    Show pixel values as sets the colour bar beside the picture, the activity plot, the detection level and exports. Temperature needs a recording with temperature calibration; others always show raw counts. Recordings you've already scanned are converted, so there's no need to scan again.

    If a camera's clock was wrong, enter the correction to add: for example −90 if it was 1½ minutes fast, or 3600 if it was still on GMT during BST. Every time shown, exported and reported uses it.
